# Figures organization

Canonical map of `paper_artifacts/figures/` for anyone generating, compiling, or citing paper/talk assets.

`paper_artifacts/` is gitignored (regenerable). This file lives at the repo root so it stays visible. The older catalog `paper_artifacts/VISUAL_ASSETS.md` still describes *what each render shows*; this file describes *where it lives now* (reorganized 2026-08-17).

Generation scripts live in `paper_artifacts/scripts/` and write into the folders
below via constants in `paper_artifacts/common.jl`. Measured numbers live in
`paper_artifacts/data/results.json`. The manuscript is `paper/HomotopyGetsReal_paper_current.md`,
not under `figures/src/`.

## Layout

```
paper_artifacts/figures/
├── paper/          current paper-facing renders (shared with the talk)
│   ├── curves/
│   ├── surfaces/
│   ├── pipeline_steps_curve/
│   └── pipeline_steps_surface/
├── talk/           talk-only renders
├── src/            authoring sources (.tex, .md)
├── exports/        compiled PDFs and LaTeX aux files
└── archive/        dated superseded renders — do not cite as current
```

Compile the decks from `src/`:

```bash
cd paper_artifacts/figures/src
./compile_talk.sh
```

That writes `exports/talk.pdf` (current 25-slide deck) and `exports/talk_lean_23slides.pdf` (older 23-slide deck). Paths in both `.tex` files are relative to `src/`:

- `\figpaper` → `../paper`
- `\figtalk` → `../talk`

## Regenerating renders

From the repo root, with `paper_artifacts/` as the Julia project:

```bash
julia --project=paper_artifacts paper_artifacts/scripts/curve_examples.jl
julia --project=paper_artifacts paper_artifacts/scripts/sphere_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/ellipsoid_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/taubin_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/taubin_singular_structure_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/torus_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/pipeline_steps_curve_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/pipeline_steps_surface_example.jl
julia --project=paper_artifacts paper_artifacts/scripts/residual_histograms.jl
```

`paper_artifacts/common.jl` defines `PAPER_CURVES_DIR`, `PAPER_SURFACES_DIR`, `PAPER_PIPELINE_CURVE_DIR`, `PAPER_PIPELINE_SURFACE_DIR`, and `TALK_FIGURES_DIR`. New scripts should write there, not to `figures/` itself.

A duplicate `astroid_bertini_real_sampled.pdf` previously sat at
`paper_artifacts/astroid_bertini_real_sampled.pdf`. It was byte-identical to
`figures/paper/curves/astroid_bertini_real_sampled.pdf` and was removed.
